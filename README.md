# Bíblia em Contexto

Leitura bíblica em português, busca e comentários de estudo. Paleta em pergaminho, areia, taupe e bronze, com modo escuro.

Texto: Bíblia Portuguesa Mundial (BPM), em domínio público e ainda em revisão pela fonte. Comentários editoriais produzidos com auxílio de IA, sem revisão teológica humana. Consulte Sobre & fontes no site.

## Hospedagem

Em Settings → Pages, selecione Deploy from a branch, a branch fileOrganizer e a pasta / (root). Salve para publicar com GitHub Pages.
