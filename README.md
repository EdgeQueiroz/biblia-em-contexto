# Bíblia em Contexto

Site de leitura bíblica, busca e estudo em português, com paleta em pergaminho, areia, taupe e bronze.

## Publicação

GitHub Pages usa a branch `fileOrganizer`, pasta `/docs`. O conteúdo servido está em `docs/`; futuras atualizações devem ser aplicadas nessa pasta. A cópia original na raiz foi preservada.

Texto: Bíblia Portuguesa Mundial, em domínio público e ainda em revisão pela fonte. Comentários editoriais com auxílio de IA, sem revisão teológica humana. Consulte Sobre & fontes no site.
